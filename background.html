Long Division

Description

Long division is used to divide one polynomial by another polynomial.

Rules

  • Divide the leading terms.
  • Multiply.
  • Subtract.
  • Bring down the next term.
  • Repeat until complete.

When to Use It

Long division is used whenever synthetic division cannot be used.

Example

(x³ + 4x² - x + 6) ÷ (x² + 1)

Synthetic Division

Description

Synthetic division is a shortcut method used when dividing polynomials by expressions in the form x - c.

Rules

  • Write only the coefficients.
  • Use the zero of the divisor.
  • Bring down the first coefficient.
  • Multiply and add repeatedly.

When to Use It

Synthetic division is used when the divisor is a linear expression such as x - 2.

Example

(x³ + 5x² + 2x - 8) ÷ (x - 2)
