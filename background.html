Background Information

Long Division

Description

Long division is used when dividing polynomials by other polynomials.

Rules

  • Divide leading terms.
  • Multiply.
  • Subtract.
  • Bring down the next term.

When to Use It

Use when the divisor is not in the form x - c.

Example

(x³ + 4x² - x + 6) ÷ (x² + 1)

Synthetic Division

Description

Synthetic division is a shortcut method for certain polynomial divisions.

Rules

  • Write only coefficients.
  • Use the root of the divisor.
  • Bring down the first coefficient.
  • Multiply and add repeatedly.

When to Use It

Use when dividing by x - c.

Example

(x³ + 5x² + 2x - 8) ÷ (x - 2)
