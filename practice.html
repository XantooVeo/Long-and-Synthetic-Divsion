Synthetic Division Problems

Try solving the following problems using synthetic division before checking your answers.

  1. (x³ + 5x² + 2x - 8) ÷ (x - 2)
  2. (2x⁴ - 3x² + 6) ÷ (x + 1)
  3. (x⁴ - 4x² + 3) ÷ (x - 1)

Long Division Problems

Try solving the following problems using polynomial long division.

  1. (x³ + 4x² - x + 6) ÷ (x² + 1)
  2. (3x⁴ - 2x³ + 5x - 7) ÷ (x² - x + 2)
  3. (x⁵ + 2x³ - 4) ÷ (x² + 3)

Challenge Problem

(4x⁴ - 7x³ + 2x² - 5x + 1) ÷ (x - 3)
